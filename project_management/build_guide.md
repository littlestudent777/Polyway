# Порядок сборки проекта
> В данном руководстве описаны шаги для сборки конечного APK с использованием Android SDK для ОС Windows без Android Studio
0. Для начала работы потребуется установленный *JDK* (vers. >= 22)
1. Порядок настройки *Android SDK*: <br>
1.1. Скачать архив *Android Tools SDK (Command line tools only)* <br>
1.2. Создать директорию для *Android SDK* (далее `android_sdk`) <br>
1.3. Распаковать скачанный архив в `android_sdk`. В каталоге `cmdline-tools` создать директорию `latest` и перенести туда оставшиеся файлы и папки из `cmdline-tools`. <br>
1.4. В системных переменных инициализировать переменную `%ANDROID_HOME%` -- полный путь к директории `android_sdk`. В переменных пути добавить путь к директории `bin` -- `%ANDROID_HOME%\cmdline-tools\latest\bin`.
2. Перейти к корневой папке проекта. <br>
3. Для сборки отладочной версии приложения выполнить команду `gradlew.bat assembleDebug`. После окончания сборки собранный APK будет доступен в директории `app\build\outputs\apk\debug`.
4. Для сборки релизной версии приложения выполнить команду `gradlew.bat assembleRelease`. После окончания сборки собранный APK будет доступен в директории `app\build\outputs\apk\release`.
